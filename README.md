# 🌿 Plants and Nature — Classroom Presentation Website

A polished, interactive single-page presentation website built for an engaging **7–8 minute classroom presentation** titled **“Plants and Nature.”**

Designed for student presentations, projector delivery, and live audience interaction, featuring a calming nature palette of deep forest green, warm cream, and sky-blue accents, accompanied by an interactive physical mystery pouch guessing game.

---

## 🚀 Quick Start

### Option 1: Direct File Launch (No installation required)
Simply double-click [`index.html`](file:///d:/BVBCET%201st%20semester/PC/nature/index.html) in any modern web browser (Google Chrome, Microsoft Edge, Mozilla Firefox, Apple Safari).

### Option 2: Local HTTP Server
Run with Node.js:
```bash
node server.js
```
Then navigate to `http://localhost:3000` in your web browser.

## 🌿 Mystery Plants Included

All plants feature verified, authentic botanical photography, scientific names, sensory identification clues, carefully phrased traditional benefits (without disease-curing claims), and memorable facts:

1. **Banyan Tree** (*Ficus benghalensis*): Massive aerial prop roots; national tree of India; single trees forming living forests.
2. **Neem Tree** (*Azadirachta indica*): Serrated bitter leaves; traditional neem twigs (*datun*); compound azadirachtin repellent.
3. **Hibiscus** (*Hibiscus rosa-sinensis*): Scarlet trumpet blossoms with protruding stamina column; vitamin-C rich teas; Polynesian relationship status custom.
4. **Tulsi / Holy Basil** (*Ocimum tenuiflorum*): Distinctive peppery aromatic foliage; comforting herbal infusion; nighttime carbon dioxide absorption.
5. **Peepal / Sacred Fig** (*Ficus religiosa*): Heart-shaped leaf with slender drip-tip; keystone sanctuary for hundreds of bird and pollinator species.
6. **Snake Plant** (*Dracaena trifasciata* / *Sansevieria*): Architectural upright sword leaves with gold margins; NASA clean air toxin filtration; night-time CAM oxygen release.
7. **Custom Plant / Spearmint** (*Mentha spicata*): Pre-configured with crisp refreshing menthol aroma; includes a live interactive modal allowing presenters to customize the title, clues, benefits, facts, and image URL on the fly.

## ✨ Standout Visual & Audio Features

1. **Theatrical "Dry Scorched Earth" Theme (Slide 1)**:
   - Immerses the audience in an arid, terracotta desert aesthetic featuring 100% plant-free photography (Sahara Erg dunes, Zabriskie badlands, cracked desert playa).
   - Once the audience guesses, the presenter clicks **"Reveal Answer"** to unveil **🌿 Plants!**
   - Moving to Slide 2 initiates a lush green transition across the entire presentation stage.

2. **Continuous Falling Leaves Animation (`leaves.js`)**:
   - High-performance HTML5 Canvas particle system simulating realistic falling leaves with sway, 3D flip, and wind drift.
   - Automatically **disabled on Slide 1** to maintain the dry scorched aesthetic, and active on Slides 2–16.
   - Includes an on-screen toggle button (`🍃 Leaves: On/Off`) in the top bar.

3. **Zero-Dependency Procedural Nature Soundscape (`audio.js`)**:
   - Synthesizes realistic nature audio directly in the browser via the Web Audio API without needing external MP3s.
   - Choices: **Birds in Forest**, **Flowing Water**, **Wind in Leaves**, and **Sound: Off**.
   - **Automatic Audio Ducking**: Audio automatically lowers volume during speech and poem slides to ensure voice clarity.

4. **Real Mountain Video with Graceful Fallback (`video.js`)**:
   - Embedded HD mountain nature video player with center play overlay and mute controls.
   - Automatically falls back to a high-resolution alpine sunrise still image with soft camera drift if offline or paused.

5. **Widescreen 16:9 Presentation Stage**:
   - Responsive layout optimized for classroom projectors and widescreen monitors.
   - High-contrast, large typography easily legible from the back of the classroom.

6. **Presenter Notes Drawer (`P` Key)**:
   - Complete verbatim speaking scripts with clear stage directions (`[PAUSE FOR AUDIENCE GUESS]`, `[HOLD UP POUCH 2]`).
